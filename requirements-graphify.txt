# Graph tooling environment. ONE version number, ONE place -- CI installs
# from this file and so should you. See CLAUDE.md for the install command.
#
# Why this file exists at all:
#
# graphify picks its community partitioner by import probe --
# `from graspologic.partition import leiden`, falling back to networkx
# Louvain on ImportError (cluster.py:47-77). The two produce DIFFERENT
# clusterings of the same graph. Since graphify-out/graph.json is committed,
# an environment that reaches for the other partitioner silently regenerates
# a different partition, and its PRs fight the refresh bot's forever.
#
# The version number does the same thing by a different route: a different
# extractor release changes node and link extraction, which IS what the
# workflow's guard keys on, so a mismatched version produces a real PR every
# single run.
#
# Neither failure announces itself. Both look like "the graph is churning".
